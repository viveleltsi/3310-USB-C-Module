# 3310-USB-C-Module
A physical modification module to replace the default charging port of a Nokia 3310 to a usb-c port

![Nokia 3310 with the module installed](/V1.0/00-Pictures/3310Module-02.png)

# Main feature

- Allow USB-C cable to charge the phone
- The Phone modification don't require special skills or tools (screwdriver, tape)
- Part production require a 3D printer and PCB manufacturing
- Simple and cheap 3D printed case (less 2 g.)
- Small an functional custom PCB

# Assembly guide (WIP)

## Quick guide

1. Open the back lid
2. Remove the battery
3. Remove the front and the keyboard
4. Remove 4 torx screws
5. Remove the screen board
6. Remove the original charging connector module
6. From the original charging connector module, remove the speaker module
7. Add the speaker module to the 3d printed case
8. Put the PCB into the 3d printed case
9. Put the 3d printed plate above the pcb
10. Use a small tape to make fix the plate on the 3d printed case
11. Install the whole module on the phone
12. Put back the screen board, screws, front lid, battery, back lid
